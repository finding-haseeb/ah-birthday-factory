# A&H Birthday Factory

A cute birthday wish maker by **A&H Factory**. Fill in an order ticket, and a birthday card rolls off the conveyor belt with a cake you can actually blow out.

## What it does

- **Order ticket:** the birthday star's name, their age, who it's from and a message (or tap one of the ready-made lines).
- **Flavors:** strawberry, mint, lemon, blueberry or grape.
- **Party buddies:** bunny, bear, kitty, chick or froggy, each in a party hat.
- **Blow-out cake:** tap each candle to blow it out. When the last one goes out: "Wish made!", confetti and a happy buddy.
- **Birthday song:** plays the Happy Birthday tune in the browser.
- **Share link:** copy a link that holds the whole card. Your friend opens an envelope and the card pops out.
- Light and dark mode, works on phones, respects reduced motion.

## Run it

It's one file with no build step. Open `index.html` in a browser, or host the folder anywhere that serves static files (for example GitHub Pages).

Share links use the address of the page they were made on, so make cards from the hosted copy if you want to send them to friends.
